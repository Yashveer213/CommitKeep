# Stage 1 — UI and UX

## Goal

Produce a complete, reviewable product journey before any live GitHub write is enabled.

## Current milestone

- Black, white, and neutral-gray design system.
- Restrained glass surfaces, depth, and smooth transitions.
- Responsive overview, repositories, history, and saved-work views.
- Connection dialog that clearly states the integration is not active.
- Keyboard-safe tabs, visible focus, and reduced-motion support.
- Private workspace identity display and a monochrome favicon.

## Remaining Stage 1 screens

- Three-step first-run setup: GitHub connection, repository selection, and automation configuration.
- Schedule editor with local time and timezone.
- Repository detail with branch and commit-mode choices.
- Change preview with files, additions/deletions, and commit message.
- Populated history, run detail, paused, disconnected, failure, and conflict states.
- Mobile navigation and install prompt preview.

## Exit criteria

- The complete primary journey can be reviewed without a live GitHub token.
- Desktop and mobile layouts work without horizontal overflow.
- Keyboard navigation and reduced motion are verified.
- Simulated data and actions are visibly labeled.
- Product copy explains consequences before repository writes.
